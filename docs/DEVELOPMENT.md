# Développement

Node.js 20+ et npm 10+ sont recommandés. Installez les dépendances avec `npm install`. Les commandes disponibles sont `npm run dev`, `npm run dev:extension`, `npm run build`, `npm run lint`, `npm run format`, `npm run typecheck` et `npm test`.

La traduction n’a pas encore de fournisseur actif. Pour le MVP gratuit, la cible documentée est une instance LibreTranslate locale ou auto-hébergée. Ne placez jamais de clé API dans `.env`, le manifest, le code client ou `chrome.storage` sans décision d’architecture dédiée ; les secrets doivent rester côté serveur.
